## Patterns used
1. Open on something already alive (running hero) inside a real client review — never on a blank generate.
2. Close-up on the knob while it moves, then pull out so the viewer sees all pages move together (Screen Studio grammar: push in on cause, pull out on effect).
3. Big visual deltas first (speed, glow, dark palette), then a structural one (layout) — the official demo has no structural knob, so this is our differentiator.
4. A human twist: the client wants one page different → unlink → proof chip "linked in 2 boards" (official has no cross-page linkage at all).
5. End on a sign-off (Approved) and hold ≥3 s. Pure-screen: no captions/music.
